# 运营人员使用说明

## 你需要准备

- 一台 Windows 电脑和普通 Google Chrome。
- 已登录的小红书创作服务平台、抖音创作者中心账号。
- 管理员发给你的 `DailyForge-Operator.zip` 和一次性连接码。

你不需要安装编程软件，也不需要填写飞书、AI 或数据库密钥。

## 首次安装

1. 解压安装包，双击 `Install-DailyForge.cmd`。
2. 浏览器会打开“DailyForge 本机草稿助手”。填写公司 DailyForge 地址、电脑名称和一次性连接码。
3. 点击“准备浏览器助手”，复制页面显示的扩展目录。
4. 在 Chrome 地址栏打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择刚复制的目录。
5. 回到向导点击“完成扩展配对”。
6. 点击“打开小红书和抖音”，分别完成登录，再点“重新检查”。
7. 点击“准备下一条内容”做首次验收。

首次加载 Chrome 扩展是唯一需要手动完成的浏览器设置。之后本机助手会随当前 Windows 用户登录自动启动。

## 每天怎么用

1. 保持电脑开机，Chrome 中两个平台保持登录。
2. DailyForge 会从飞书领取已生成的内容，上传图片、填写标题和正文，并尝试保存为平台草稿。
3. 打开小红书和抖音草稿箱，检查图片顺序、标题、正文和话题。
4. 确认符合要求后，由你手动点击最终发布。

系统不会自动点击最终发布。验证码、账号验证、平台风控或规则提示需要你本人处理。

## 卸载

运行安装包中的 `Uninstall-DailyForge.cmd`。卸载会清除：

- 开机启动项。
- 本机设备连接凭证。
- 已下载的图片缓存。
- 本机 Chrome 控制桥的配对数据。

最后到 `chrome://extensions` 手动移除 DailyForge 扩展。
