# 飞书接入

## 企业自建应用

创建企业自建应用并配置以下环境变量：

```env
FEISHU_APP_ID=
FEISHU_APP_SECRET=
FEISHU_BITABLE_APP_TOKEN=
FEISHU_TABLE_ID=
```

应用需要具备多维表格记录读写和素材上传权限，并被添加为目标多维表格的协作者且拥有编辑权限。

## 多维表格

数据表名称建议为“小红书每日内容”。字段必须按以下名称和类型建立：

| 字段 | 类型 |
| --- | --- |
| 生成日期 | 日期 |
| 任务ID | 单行文本 |
| 产品名称 | 单选 |
| 级别 | 单选，选项为“四级”“六级” |
| 内容模块 | 单选 |
| 内容类型 | 单选 |
| 选题 | 单行文本 |
| 标题候选 | 多行文本 |
| 最终标题 | 单行文本 |
| 正文 | 多行文本，正文末尾包含一行横向排列的话题标签 |
| 封面主标题 | 单行文本 |
| 封面副标题 | 单行文本 |
| 图片 | 附件，可包含 4 个文件 |
| 图片脚本 | 多行文本 |
| 生成状态 | 单选，选项为“已生成”“需要人工检查” |
| 发布状态 | 单选，选项为“待发布”“已发布” |
| 备注 | 多行文本 |
| Supabase ID | 单行文本 |

`任务ID` 用于同步幂等检查，不要删除或改名。重试飞书同步时，系统会先搜索该字段，找到已有记录就不会再新增。

正文与话题标签之间保留一个空行，标签之间使用一个空格。四张图片按封面、内容页 1、内容页 2、内容页 3 的顺序保存在同一个“图片”附件字段中。

## 验证顺序

1. 获取 `tenant_access_token`。
2. 上传一张小于 20 MB 的 PNG 到 `bitable_image`，确认获得 `file_token`。
3. 手动调用新增记录接口，确认附件字段可预览。
4. 删除测试记录，再从 DailyForge 运行完整任务。

如果字段不存在、字段类型不匹配或应用没有权限，任务会停止在 `sync_feishu` 并在运行台显示飞书错误码。
