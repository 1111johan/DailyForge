# 飞书接入

## 应用权限

创建企业自建应用，发布可用版本，并为应用开通：

- 多维表格数据表与记录读写权限。
- 云空间素材上传与下载权限。
- 目标多维表格的协作者编辑权限。

配置 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_BITABLE_APP_TOKEN` 和现有内容表的 `FEISHU_TABLE_ID` 后运行：

```powershell
npm run setup:feishu
```

脚本会补齐内容表字段，并创建“DailyForge 定时计划”和“DailyForge 系统设置”两张表。把命令返回的两个表 ID 分别配置为：

```env
FEISHU_SCHEDULE_TABLE_ID=
FEISHU_SETTINGS_TABLE_ID=
```

脚本可重复执行，不会删除或覆盖历史记录。

## 内容表

业务字段：

| 字段 | 类型 |
| --- | --- |
| 最终标题 | 单行文本，主字段 |
| 生成日期 | 日期 |
| 任务ID | 单行文本 |
| 产品名称 | 单选 |
| 级别 | 单选：四级、六级 |
| 内容模块 | 单选 |
| 内容类型 | 单选 |
| 选题 | 单行文本 |
| 标题候选 | 多行文本 |
| 正文 | 多行文本 |
| 封面主标题 | 单行文本 |
| 封面副标题 | 单行文本 |
| 图片 | 附件，可包含 4 个文件 |
| 图片脚本 | 多行文本 |
| 生成状态 | 单选：已生成、需要人工检查 |
| 发布状态 | 单选：待发布、已发布 |
| 备注 | 多行文本 |

内部字段由初始化脚本创建：`系统数据`、`系统状态`、`任务阶段`、`下次执行`、`锁定时间`。不要手动修改这些字段。

`任务ID` 用于幂等检查。正文末尾包含一行横向排列的话题标签；4 张图按封面、内容页 1、内容页 2、内容页 3 的顺序保存在同一个“图片”字段。

旧的“图片1–4”“话题标签”和“Supabase ID”字段可以保留历史内容，系统不再写入。

## 容量与限制

- 单张上传图片必须小于 20 MB。
- 同一多维表格的素材上传和记录写入采用串行队列。
- 单张数据表最多 20,000 条记录。
- 运行台图片代理只用于预览，附件本身持续保存在飞书记录中。
