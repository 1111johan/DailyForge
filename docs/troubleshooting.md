# 故障排查

## 向导显示“未连接 DailyForge”

- 确认地址以 `https://` 开头且能在浏览器打开。
- 一次性连接码只有 20 分钟有效，并且只能使用一次；过期后让管理员重新创建。
- 让管理员确认这台电脑在运行台中没有被停用。

## Chrome 助手不可用

- 确认已在 `chrome://extensions` 加载向导显示的扩展目录。
- 扩展文件更新后，在扩展页点击一次“重新加载”，再刷新小红书和抖音页面。
- 回到向导重新点击“完成扩展配对”。
- 不要把本机 `16881` 端口开放到局域网或公网。

## 图片或文案没有填入

- 确认平台页面已经登录，且没有验证码、实名确认或其他弹窗。
- 飞书内容必须包含最终标题、正文和 4 张有效图片。
- 单张图片必须是 PNG、JPEG 或 WebP，且不超过 20 MB。
- 在向导点击“准备下一条内容”查看具体错误；管理员也能在飞书“社媒错误”字段看到结果。

## 一个平台成功、另一个失败

DailyForge 独立记录小红书和抖音状态。管理员在运行台只重置失败的平台后，下次不会重复建立已经成功的平台草稿。

## 草稿按钮失效

平台页面结构可能更新。先在 Chrome 扩展页重新加载扩展并刷新创作页面；仍失败时保留页面截图和飞书“社媒错误”内容，交给管理员更新平台适配器。最终发布按钮不在自动化范围内。

## 云端今天没有生成

- `/api/health` 检查 AI、飞书和安全配置。
- 检查飞书定时计划是否启用、时间是否为上海时区。
- 检查 Supabase 是否只有一条启用的 `dailyforge-online-heartbeat`。
- AI 中转站网络失败只影响新内容生成，不影响已经保存在飞书的历史内容建立草稿。
